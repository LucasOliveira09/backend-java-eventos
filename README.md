## 📌 Sobre o Projeto
API RESTful desenvolvida em Java e Spring Boot para controle completo de gestão de eventos, inscrições de participantes e venda de ingressos com validações de regras de negócio em camadas.

---

## 🏛️ Arquitetura & Padrões
* **Controllers:** Endpoints REST padronizados com respostas HTTP semânticas.
* **Services:** Regras de negócio isoladas da camada de persistência.
* **Repositories:** Acesso a dados via Spring Data JPA com queries otimizadas.
* **DTOs & Bean Validation:** Validação rigorosa dos dados de entrada.
